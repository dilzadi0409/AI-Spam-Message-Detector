# AI Spam Message Detector

A beginner-level machine-learning web app built with Python, Streamlit, TF-IDF, and Logistic Regression.

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Create a virtual environment (optional but recommended):
   `python -m venv venv`
4. Activate it:
   Windows: `venv\Scripts\activate`
5. Install dependencies:
   `pip install -r requirements.txt`
6. Start the app:
   `streamlit run app.py`

## What I learned
- Text preprocessing and TF-IDF vectorization
- Training a Logistic Regression classifier
- Making predictions from user input
- Building a simple interface with Streamlit

## Important limitation
This project contains a small sample dataset for learning and demonstration. It is not production-ready and may misclassify messages. Use a larger, balanced, properly sourced dataset before claiming real-world accuracy.
